# Backlog

The baseline goal is one working happy path through the API. When it works end to end, is tested, and runs in CI, the baseline is ready; everything after that is an improvement.

MVP items come with a suggested default to confirm or replace.

## The happy path

1. A client creates a company.
2. A client adds contacts, some of them at that company.
3. A client lists contacts a page at a time, and narrows the list by company or by name.
4. A client opens a deal with the company, with one of its contacts as the main person.
5. A client updates and deletes records, and the references between them stay valid.
6. Every step is covered by tests that run locally and in CI.

## MVP: decide to build the happy path

- [ ] **Records:** companies, contacts, and deals, each with create, read, update, delete, and list. *Suggested:* the fields named in spec 001. *Decided (001 plan):* those fields, over REST endpoints per record type.
- [ ] **Error responses:** one error format for bad input, naming each problem. *Suggested:* the HTTP status plus a list of field errors. *Decided (001 plan, D7):* RFC 9457 problem details with an `errors` list of `{field, message}`.
- [ ] **Deleting referenced records:** what happens to contacts and deals when their company or contact is deleted. *Suggested:* they stay, with the reference cleared. *Decided (spec 001 R17–R19, plan D6):* they stay; foreign keys clear the reference (`ON DELETE SET NULL`).
- [ ] **Contact list:** contacts are listed a page at a time, filtered by company or by name. *Suggested:* pages numbered from 1, with a default and a maximum page size. *Decided (spec 001 R10–R12, plan D10):* `page` from 1, `size` 1–100, default 20, sorted by id.
- [ ] **API description:** a machine-readable description of the API. *Suggested:* generated from the code. *Decided (001 plan, D11):* generated by springdoc at `/v3/api-docs`.
- [ ] **CI:** a workflow that runs every test on each push and pull request. *Suggested:* GitHub Actions on `main` and pull requests. *Decided (001 plan, D13):* GitHub Actions on every push and pull request.
